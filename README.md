# Co-workers

A modern workplace collaboration platform for teams, departments, communication, meetings, tasks, attendance, leave, approvals, files and announcements.

## Stack
- React + Vite
- Supabase
- Responsive enterprise UI

## Setup
1. `npm install`
2. Create a Supabase project.
3. Copy `.env.example` to `.env` and add your Supabase URL and anon key.
4. Run `supabase/schema.sql` in Supabase SQL Editor.
5. `npm run dev`
